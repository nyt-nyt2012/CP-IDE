测试点配置文件格式

配置文件采用 INI 风格，[config] 段为全局参数，[tests] 段列出测试点。

[config]
std = c++14            ; C++ 标准
time_limit = 1000      ; 默认时间限制（毫秒）
memory_limit = 256     ; 默认空间限制（MB）
checker = default      ; default / strict / ignore_trailing_space / wcmp / ncmp / custom
output_limit = 256     ; 单次输出上限（KB）
compile_args = -Wall   ; 追加的编译参数

[tests]
1 | 1.in | 1.out | 1000 | 256
2 | 2.in | 2.out
3 | 3.in | 3.out | 2000 | 512 | ncmp

每个测试点字段依次为：编号 | 输入文件 | 输出文件 | 时间限制(ms) | 空间限制(MB) | 比较方式，后三项可省略。

也支持通配写法，例如 1-10.in | 1-10.out 会展开为 10 个测试点；*.in 会按文件名顺序配对 *.out。

不提供配置文件时，IDE 会自动把同名 .in 与 .out 配对。
